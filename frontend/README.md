# 🚀 TaskFlow - Personal Productivity Dashboard

A full-stack task management application designed to help users organize their day efficiently. Built with the **MERN Stack** (MySQL, Express, React, Node.js), this project features secure user authentication, real-time task updates, and a personalized profile management system.

## 🌟 Features

* **🔐 Secure Authentication:** Users can register and login securely (Password hashing & Validation).
* **📝 Task Management (CRUD):** Create, Read, Update (Mark as Done), and Delete tasks instantly.
* **👤 User Profile:** Dedicated profile section to view user details and update Bio/Avatar.
* **🎨 Modern UI:** Clean, responsive interface built with React and styled with CSS3.
* **🗄️ Cloud Database:** Data is persisted using a managed **MySQL** database on Aiven.

## 🛠️ Tech Stack

* **Frontend:** React.js (Vite), React Router, Axios
* **Backend:** Node.js, Express.js
* **Database:** MySQL (Cloud-hosted on Aiven)
* **Styling:** CSS3 (Modern Flat Design)
